# Nouvelle Convergence

Notre programme repose sur une idée simple mais ambitieuse : dépasser les divisions idéologiques entre partis pour construire un projet collectif, fondé sur des compromis équilibrés.

Nous croyons que, malgré leurs divergences, les sensibilités politiques partagent des préoccupations communes qui, lorsqu'elles sont réconciliées, peuvent transformer le pays.

## Comment ça marche

Les propositions se déposent et se votent dans l'onglet **Discussions**, catégorie *Propositions*.

- Une proposition = un titre, des mesures en une ligne chacune, et pour chaque mesure **qui paie**.
- Les chiffres sont sourcés ou absents. Un chiffre sans source est retiré.
- Ce que la proposition écarte est écrit, pas sous-entendu.
- Les contraintes connues, droit européen, coût de transition, sont signalées par ⚠.

Le vote dit si une proposition est défendable pour des sensibilités différentes ; il ne remplace pas la relecture.

## Ce que nous ne faisons pas

Nous ne qualifions pas les chiffres, nous ne jugeons pas les personnes, nous ne reprenons pas le vocabulaire d'un camp.
